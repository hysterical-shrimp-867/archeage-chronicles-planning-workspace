# ArcheAge Chronicles Planning Workspace — feature reference

Start with character profiles, organize activity notes, and keep equipment planning close at hand. These are the main areas covered by ArcheAge Chronicles Planning Workspace.

| Section | Description |
|---|---|
| Character profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Activity notes | Session and activity information grouped by the task or context it belongs to. |
| Equipment planning | Equipment categories and the associated selection or configuration options. |

The project page follows the same section structure.
